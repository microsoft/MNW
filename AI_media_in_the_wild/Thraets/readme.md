# AI Deep and Cheap Fakes Africa – from Thraets
A collection of AI-generated and manipulated media (deepfakes and cheapfakes) found on social media across Africa, with the original post link, an archived copy, the country, and the type of fake for each item. The layout follows the *AI media in the wild* section of the [MNW benchmark](https://github.com/microsoft/MNW/tree/main/AI_media_in_the_wild).

## Contents
| Folder | Items | Files | 
| :---:   | :---: | :---: |
| Images | 72   | 72 images |
| Videos | 23   | 17 videos + 6 removed (archive link only)|
| **Total** | **95**   | **89 files**|

Each folder has a `likely_manipulated/` subfolder with the files and a `readme.md` listing every item's live link and archive link, in the same format as MNW. Country, fake type, platform, Report ID, original text and translation for every item are in [`metadata/shortlist.csv`](metadata/shortlist.csv) and [`metadata/shortlist.xlsx`](metadata/shortlist.xlsx).

## Labels
- Deepfakes
- Cheapfakes
  
All the content included here is AI-generated. The classification between * *deepfakes* * and * *cheapfakes* * depends on how costly they were to create. These labels can be reviewed in [`metadata/shortlist.csv`](metadata/shortlist.csv) and [`metadata/shortlist.xlsx`](metadata/shortlist.xlsx).

## File names
Files are named `M001`, `M002` … within each folder (M = likely manipulated, as in MNW). The original Report ID for each file is in the metadata files.

## Known gaps
- Some archive links contain `/wip/`, meaning the archive.is capture may not have finished; these are flagged in the Notes column of the metadata files.
- Images are kept in their original format (JPEG, PNG or AVIF) without recompression.
